03 / LOAD THE BOARD

Flash the firmware

03 / 09

The firmware is already in the AirRing repository. Build it with PlatformIO, flash over USB and watch the serial monitor for the sensor status.

TERMINAL / PLATFORMIOFEDORA · LINUX
# Install PlatformIO oncepython3 -m pip install --user pipx python3 -m pipx ensurepath pipx install platformio# Build the firmwarecd AirRing/firmware/airring pio run# Connect the ESP32, then flashpio run -t upload# Open the serial monitorpio device monitor
Serial speed: 115200 baud
Fedora packagessudo dnf install python3 python3-pip git make

Use a data USB cable. If the board does not appear, check your USB serial driver and user permissions.

✓What success looks likeThe serial monitor prints “AirRing ready” and the board advertises as AIRRING.

06 / 09
